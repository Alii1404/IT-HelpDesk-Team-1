IT Help Desk – University Technical Support System
About the Project

IT Help Desk is a university technical support management system. It allows students and university employees to report technical problems and IT specialists to manage and resolve them.

Main Features
User login
Create technical support tickets
View ticket list
Change ticket status
Filter tickets by category and status
View ticket details
Dashboard statistics

Installation
Clone the repository.
Open the project using Visual Studio or VS Code.
Configure the SQL Server connection.

Git Workflow

All developers work on separate feature branches and submit Pull Requests to the main branch. Direct pushes to main are not allowed.
